复习与刷题方法

第一遍 · 理解为主

做法：看完题目直接看答案，避免硬想半天想不出来还挫败信心。
目标：理解解题思路和代码逻辑，能清晰口述解题步骤和方法即可。

第二遍 · 复现检验

做法：看题后先回忆并默想思路，再对照答案验证；思路对了，就按自己的思路一步步写出代码（可参考答案，慢慢做到完全独立）。
✅ 第二遍进行中就可以开始投简历。不必追求完全熟练再行动——面试本身也是学习，而且有的面试很看运气，缺人的时候随便问问你就过了。
🔁 探险模式复习节奏：新题与旧题滚动并行。先按关卡完成新题，再复习已学模板和错题；防遗忘比单纯堆题量更重要。

🧮 复杂度反推速查笔试神器：先看数据范围，再想算法

数据规模 n可接受复杂度该想到的算法
n ≤ 20O(2ⁿ) / O(n!)回溯、枚举子集、全排列
n ≤ 500O(n³)区间 DP、Floyd
n ≤ 5×10³O(n²)双重循环 DP、朴素比较
n ≤ 10⁵ ~ 10⁶O(n log n)排序、堆、二分、分治
n ≥ 10⁶O(n) / O(log n)哈希、双指针、前缀和、位运算、单调栈
💡 笔试拿到题先瞄一眼 n 的范围，反推能用的复杂度，再想对应主题的算法——比对着暴力硬优化快得多。超时（TLE）九成是复杂度选错了。
